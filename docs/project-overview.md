# GameMaster 项目实现概览

## 项目概述

GameMaster 是一个基于 Koishi 框架的 TRPG（桌上角色扮演游戏）机器人插件，提供完整的会话管理、角色卡系统、骰子和规则系统支持。

**版本号**：0.0.1
**许可证**：MIT
**框架**：Koishi 4.x

## 核心特性

### 1. 多规则系统支持

使用适配器模式实现多规则系统：
- ✅ **Generic**：通用规则系统（1d100 检定）
- ✅ **CoC7**：克苏鲁的呼唤 7版（完整实现）
- ⏳ **D&D 3R**：龙与地下城 3R 版（待实现）

### 2. 完整的角色卡系统

- 支持多种规则系统的角色卡格式
- JSON 格式存储，灵活可扩展
- 多会话独立激活状态
- 角色归档、转移、导入导出

### 3. 强大的骰子系统

- 复杂表达式解析（3d6+2d4-1）
- 高级机制（保留/丢弃、重骰、爆骰）
- 友好的输出格式

### 4. 多格式导出

- 会话记录：文本、Markdown、JSON
- 角色数据：JSON
- 支持完整的统计信息

### 5. 权限系统

- 基于角色的访问控制（RBAC）
- 三个角色层级：creator、admin、member
- 细粒度的权限验证

```
┌─────────────────────────────────────────┐
│          命令层 (Commands)               │
```

## 快速开始

### 1. 创建会话

```
会话创建 "我的第一个TRPG团" coc7
```

### 2. 加入会话

```
会话加入 1
```

### 3. 创建角色

```
角色创建 "调查员A" '{"str":50,"con":50}' '{"spot_hidden":60}'
```

### 4. 开始游戏

```
.check 侦查
.r 3d6
```
