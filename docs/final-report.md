### 2. CoC7 角色服务实现 (100%)

**新建文件**: [src/rule/coc7/coc7-character-service.ts](../src/rule/coc7/coc7-character-service.ts)

**实现内容** (约700行代码):

1. **getCombatData()** - 获取角色战斗数据
   - 读取角色属性、技能、装备
   - 计算 DB、体格等衍生属性
   - 返回 CoC7CharacterCombatData

2. **applyDamage()** - 应用伤害
   - 更新角色 HP
   - 判断意识丧失、死亡状态
   - 持久化到 character.metadata.combat

3. **getSkillValue()** - 获取技能值
   - 支持中英文技能名称
   - 自动规范化技能名

4. **getAttributeValue()** - 获取属性值
   - 类型安全的属性读取

5. **addWeapon()** - 添加武器
   - 验证武器存在性
   - 验证角色所有权

6. **createCharacter()** - 创建角色
   - 验证 CoC7 必需属性（8个核心属性）
   - 调用适配器计算衍生属性
   - 调用全局服务持久化

7. **updateCombatState()** - 更新战斗状态
   - 更新 HP、Sanity、状态效果

8. **formatCharacterCard()** - 格式化角色卡
   - 美化的角色卡展示

## 🎯 架构改进

### 改进前的问题

1. ❌ 战斗命令使用硬编码默认值
2. ❌ 伤害不持久化
3. ❌ 代码重复（coc7-commands.ts 和 combat-commands.ts）
4. ❌ 没有统一的规则服务接口

### 改进后的架构

```
┌─────────────────────────────────────────────────────────────┐
│                   战斗/游戏层                              │
│  - .战斗开始, .攻击, .闪避, .反击, .伤害                    │
└────────────────────┬────────────────────────────────────────┘
                     │ 依赖接口
┌────────────────────▼────────────────────────────────────────┐
│          规则服务实现层 (CoC7CharacterService)            │
│  - getCombatData(), applyDamage(), getSkillValue()        │
│  - createCharacter(), updateCombatState()                 │
└────────────────────┬────────────────────────────────────────┘
                     │ 调用
┌────────────────────▼────────────────────────────────────────┐
│            规则适配器层 (CoC7Adapter)                      │
│  - createCharacter(), normalizeSkillName()                │
│  - calculateDB(), 技能检定逻辑                             │
└────────────────────┬────────────────────────────────────────┘
                     │ 继承
┌────────────────────▼────────────────────────────────────────┐
│       规则服务接口层 (IRuleCharacterService)              │
│  - 定义统一的服务接口                                       │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│          全局角色卡服务层 (CharacterService)               │
│  - 数据库 CRUD 操作                                         │
│  - 角色与会话的关联管理                                     │
└────────────────────┬────────────────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────────────────┐
│              数据持久化层 (Database)                         │
└─────────────────────────────────────────────────────────────┘
```

## 💡 核心特性

### 1. 真实角色数据

**之前**:
```typescript
const skillValue = 50  // 硬编码
const db = calculator.calculateDB(50, 50)  // STR=50, SIZ=50
```

**之后**:
```typescript
const skillResult = await this.characterService.getSkillValue(character.id!, weapon.skill)
const skillValue = skillResult.value
const str = await this.characterService.getAttributeValue(character.id!, 'str')
const db = calculator.calculateDB(str, siz)
```

### 2. 伤害持久化

**之前**: 伤害仅显示，不保存
**之后**: 伤害永久保存到 `character.metadata.combat.currentHp`

### 3. 战斗状态管理

新增命令:
- `.角色恢复` - 恢复 HP 和 SAN
- `.角色状态` - 查看详细战斗状态

### 4. 代码质量提升

- 🔒 **类型安全**: 完整的接口定义
- 🧪 **可测试性**: 可以 mock 接口进行测试
- 🚀 **可扩展性**: 添加新规则系统只需实现接口
- 📦 **单一职责**: 每个模块职责明确

## ⚠️ 破坏性改动

### 对用户的影响

1. **战斗命令需要角色卡**
   - 之前: 可以直接使用战斗命令（使用默认值）
   - 现在: 必须先创建并激活角色

   **缓解**: 提供清晰的错误提示

2. **伤害会持久化**
   - 之前: 伤害仅显示，不保存
   - 现在: 伤害会永久修改角色 HP

   **缓解**: 提供 `.角色恢复` 命令
